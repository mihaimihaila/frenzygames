Magnet Tool Guide

Author: Mihai, last modified: 21/10/2026


The Magnet is a puzzle-solving power-up that helps you complete puzzles faster. When activated, it automatically places a random unsolved piece into its correct position on the board.

How It Works & Key Features

  • Easy Access: While playing, you can access the Magnet from the tools tray on the right side of your screen.
  • Usage Limit: You can use the Magnet up to 5 times per puzzle.
  • Flexible Timing: Use it at any point during gameplay, whether you want a boost right at the beginning or help finding tricky pieces near the end.
  • Tool Combinations: The Magnet works alongside other tools. For example, if the Edges filter is active, the Magnet will only place edge pieces.
  • Refilling: Need more uses? You can refill the Magnet at any time using Gems.
